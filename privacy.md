# Privacy Policy

Last updated: November 5, 2026

Armbian Restic Backup is a personal backup
application operated by its owner.

## Information Access

The application accesses Google Drive through
the Google Drive API using authorization
granted by the account owner.

Google Drive access is used only to store,
retrieve, and manage the owner's Restic
backup repository.

## Data Storage

Backup data is encrypted by Restic before
being transferred to Google Drive.

The application does not operate a public
user database or collect personal information
from other users.

## Data Sharing

The application does not sell, rent, or share
Google user data with third parties.

Google Drive is used as the storage provider
for the owner's backup repository.

## Data Retention and Deletion

The owner controls backup retention and
deletion through Restic and Google Drive.

## Security

Access credentials are maintained by the
owner on their own server.

The application is intended for personal use.
