# Armbian Restic Backup

Armbian Restic Backup is a personal backup
solution designed to protect configuration
and application data on an Armbian Linux server.

## Features

- Automated backups using Restic.
- Backup repository stored in Google Drive.
- Encrypted backup data using Restic.
- Backup verification and recovery support.
- Designed for personal server administration.

## Data and Google Drive

The application uses Google Drive through
rclone to store the user's Restic backup repository.

Backup data is encrypted by Restic before
being uploaded to Google Drive.

The application is intended for personal use
by its owner.
